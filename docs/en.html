For everyone who wants to hand their MacBook over to AI.

Yamiy is a menu-bar app that keeps your MacBook's screen dark. The display is never put to sleep, so screen capture and remote control keep working.

Download Yamiy-0.3.0.zip View the source on GitHub

Runs on Apple Silicon Macs with macOS 14 or later.

Why it exists

You don't want the screen seen, but putting the display to sleep gets in the way of remote control and automation

If you run AI agents or automations on your Mac around the clock, the display stays on. You do not want other people to see what is on it. Putting the display to sleep, on the other hand, gets in the way of remote control and automation in some situations.

Yamiy is the app to use between those two.

What goes dark

Yamiy lowers the display brightness. Screen capture and remote control still see the usual screen

Yamiy holds the display brightness at zero. The screen itself stays awake. Screen capture and remote control keep working, whatever the brightness is.

Getting the screen back

The screen lights up again only when you unlock with Touch ID

Yamiy starts in stealth. In stealth the screen is dark and the brightness keys do nothing. The state in which you can use the screen at normal brightness is called owner mode.

Stealth

The screen is dark.

The brightness keys do nothing.

This is the state right after launch.

Enter owner mode

  • Lock the screen with the Touch ID button, then unlock with your fingerprint

Return to stealth

  • Lock the screen again
  • Close the lid
  • Touch nothing for five minutes

Owner mode

The screen lights up again.

You choose the brightness in Settings.

Closing the lid makes the screen dark without waiting five minutes

Yamiy enters stealth at the moment the lid closes. When you open the lid, the screen stays dark until you unlock.

The idle time before Yamiy returns to stealth starts at five minutes. You can change it in Settings.

What Yamiy does

Six things Yamiy does to keep the screen dark

01

Keeps setting the brightness back to zero

Setting the brightness to zero once does not stick, because automatic adjustment and the like push it back. Yamiy sets it back to the minimum every 0.15 seconds.

02

Makes the brightness keys do nothing

The brightness keys on the built-in keyboard are caught by an event tap and dropped. For external keyboards, a hidutil remap is used as well. The event tap needs the Accessibility permission.

03

Enters stealth as soon as the lid closes

It does not wait for five idle minutes. When you open the lid, the screen stays dark until you unlock.

04

Can disable external displays too

External displays can be disabled in Settings.

05

Leaves one way into owner mode

You enter owner mode only by unlocking with Touch ID. After five minutes without input, Yamiy returns to stealth by itself.

06

Never puts the display to sleep

Yamiy only lowers the brightness and does not put the display to sleep. Screen capture and remote control continue.

Day to day

Click the crescent in the menu bar to see the current state

Clicking the crescent-moon icon in the menu bar opens the menu. From Open Settings in the menu, you can change these eight things.

  • The brightness in owner mode
  • The idle time before the screen goes dark again
  • Whether Yamiy starts at login
  • Whether external displays are disabled as well
  • Whether the screen returns to dark automatically when idle
  • Whether closing the lid enters stealth
  • Whether the brightness keys are blocked
  • Whether the last brightness is carried over

To quit, choose Quit Yamiy in the menu. When Yamiy quits, the keys and the brightness are restored. The menu and settings follow your system language, in Japanese or English.

Install

Three steps to install: download, move to Applications, open

  1. Download Yamiy-0.3.0.zip and unzip it.

  2. Move Yamiy.app to your Applications folder.

  3. Double-click Yamiy.app to open it.

Signing and notarization

Yamiy is signed with a Developer ID and notarized by Apple. A plain double-click opens it.

The permission that fully blocks the brightness keys

Allow Yamiy under Accessibility, in Privacy & Security in System Settings. Without the permission, holding the brightness alone still keeps the screen dark.

Starting automatically at login

You can turn on launch at login in the app's settings.

Requirements

How it works

Yamiy uses private macOS APIs, so it is distributed on GitHub and not on the Mac App Store

Yamiy uses two private APIs, DisplayServices and SkyLight. An app that uses private APIs cannot be distributed on the Mac App Store. The source code is published under the MIT License.

Brightness control
The brightness is set through the private DisplayServices API and set back to the minimum every 0.15 seconds.
Blocking the brightness keys
Keys on the built-in keyboard are caught by an event tap, and a hidutil remap is used as well for external keyboards.
External displays
The private SkyLight API is used. External displays can be disabled in Settings.
Lid open and close
Yamiy watches the clamshell state in IOKit.
Detecting lock and unlock
Yamiy uses the system's distributed notifications.

Before you install

Four things to check before you install Yamiy

Does the display sleep while Yamiy is running?

Yamiy does not put the display to sleep. Screen capture and remote control continue.

What happens if I do not grant the Accessibility permission?

Holding the brightness still works, so the screen stays dark. Fully blocking the brightness keys needs the permission.

What happens to the screen and the keys when I quit Yamiy?

The keys and the brightness are restored.

Does it run on Intel Macs, or on macOS 13 and earlier?

The requirements are an Apple Silicon Mac and macOS 14 or later.
